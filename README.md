# Project API First Demo

Bu proje, ASP.NET Core Web API yapısını öğrenmek ve RESTful servis geliştirme mantığını uygulamak amacıyla hazırlanmış temel bir API projesidir.

Projede API controller yapısı, HTTP istekleri, model sınıfları ve temel veri işlemleri üzerine odaklanılmıştır.

## Kullanılan Teknolojiler

- ASP.NET Core Web API
- C#
- .NET
- Entity Framework Core
- SQL Server
- REST API
- Swagger / API test yapısı

## Proje Özellikleri

- API controller yapısı
- HTTP GET, POST, PUT ve DELETE işlemleri
- Model sınıfları
- Veritabanı bağlantısı
- RESTful servis mantığı
- Swagger üzerinden API test edebilme
- Backend servis geliştirme pratiği

## Proje Amacı

Bu proje, ASP.NET Core Web API mimarisini öğrenmek ve frontend uygulamalarına veri sağlayabilecek backend servis yapısını deneyimlemek amacıyla geliştirilmiştir.

## Teknik Kazanımlar

- Web API proje yapısı
- Controller tabanlı endpoint oluşturma
- HTTP metotlarının kullanımı
- API ile veri gönderme ve alma mantığı
- Entity Framework Core ile veritabanı işlemleri
- Swagger üzerinden servis test etme
